# LyraLink

一个本地优先的开源桌面应用：导入、播放、整理、裁切你有权处理的音频，并制作同步歌词。

> 当前为早期 MVP。项目不会提供公共解析服务，也不会绕过登录、会员、付费、私密、地区限制、DRM 或其他访问控制。

## 当前功能

### 多音源在线搜索（试听 → 下载 → 入库）

- 独立在线搜索页，一个关键词覆盖 **B站 / 网易云 / Joox** 三个音源，分页浏览
- 在线试听（流式预览，不落盘），满意再下载到本地音乐库
- **网易云结果自动过滤 VIP / 无版权歌曲**：展示前批量校验播放地址，不会点击后才发现听不了；下载自动附带封面和 LRC 歌词
- **Joox** 提供 320k 完整曲目，自动附带封面和歌词
- 支持粘贴 B站 / 网易云 / Joox 链接直接导入；同一内容按 URL 去重，本地文件按内容哈希去重
- 从网址或完整分享文案中识别 B站链接
- 应用内搜索 B站公开视频，搜索结果可直接试听（流式预览，不落盘）、下载导入或加入歌单
- 导入前读取标题、作者、封面和时长
- 直接保存 B站当前可访问的最高质量原始音轨，避免二次有损转码
- 导入时将视频封面保存到本地，避免远程图片失效
- 本地保存音频和来源信息
- 内置简单音频库与播放器
- 支持本地 MP3、M4A、FLAC、WAV、Ogg、Opus 和 WebM 音频
- 搜索、排序、喜欢、自定义文件夹与批量整理
- 上一首、下一首、列表循环、单曲循环、随机播放和音量记忆
- 软件回收站，可恢复误删音频
- 图形化波形裁切，支持切开、删除、撤销、重做和精确时间调整
- 多片段先完整生成成功，再统一加入音乐库；原音频始终保留
- 音频导出、打开文件位置以及歌曲名称、作者、封面编辑
- 本地导入自动读取歌名、歌手、时长和内嵌封面，并检测重复文件
- 导出时将编辑后的歌名、歌手和封面写入音频元数据
- 播放列表支持拖入歌曲、拖动排序、"下一首播放"和按列表顺序播放
- 播放队列一键定位到当前播放歌曲；历史播放记录
- 整个音乐库一键备份与恢复，恢复失败自动回滚
- 回收站可设置自动保留天数
- 封面支持缩放和位置取景后保存
- 本地任务记录、错误详情和失败导入重试
- 黑胶唱片播放页：播放时唱臂落针、暂停时抬臂，单击唱片进入歌词页，双击播放 / 暂停；无封面歌曲有完整默认盘面
- 音频详情页与同步歌词显示、歌词页大字滚动联动
- 粘贴纯文本歌词，通过空格逐行打点匹配时间轴
- 一键在线搜歌词：聚合 LRCLIB、网易云、QQ、酷狗等五个公开渠道的候选结果，选择后自动填入
- B站视频带 CC/AI 字幕时，可直接抓取为带时间轴歌词
- AI 自动匹配优先使用在线歌词，找不到时回退到本地 `faster-whisper` 识别对齐，全程不调用付费 API
- AI 匹配结果复核、重新 AI 匹配与改用手动打点
- LRC 歌词导入和导出
- 桌面歌词悬浮窗：锁定与点击穿透、字号、双色、背景透明度和单/双行设置，可直接切歌和控制播放
- 最小化到托盘常驻，托盘菜单显示当前歌曲并提供播放控制、打开桌面歌词、退出
- 关闭按钮行为可设置为退出、最小化到任务栏或最小化到托盘
- 十套外观主题预设 + 自定义主题：颜色实时预览、重名校验，可保存多套配色
- 独立「处理记录」页：下载 / 导入任务的进行中、失败、历史一目了然
- 无边框窗口与自定义标题栏，支持最小化、最大化与双击标题栏
- 音乐库 JSON 自动备份和损坏回退

## 本地运行

需要：

- Node.js 22 或更高版本
- Python 3.10 或更高版本（仅 AI 自动匹配需要）

开发版本缺少离线资源时，首次点击“AI 自动匹配”会在本地数据目录创建独立 Python 环境、安装 `faster-whisper`，并下载 `small` 模型。正式离线安装包应在构建时嵌入 Python 运行时、模型和 FFmpeg，用户运行时不需要再次下载。

```bash
npm install
npm run build
npm start
```

制作离线安装资源前运行：

```powershell
npm run prepare:offline
```

该命令会在 `resources/offline` 中准备 Python、`faster-whisper`、`small` 模型和 FFmpeg。安装包配置会把该目录复制到应用资源中。此步骤只由发布者执行，普通用户无需执行。

制作 Windows 安装包：

```bash
npm run dist:win
```

脚本已内置 npmmirror 镜像（Electron 与 NSIS 工具下载不会再超时），产物输出到 `release2/LyraLink-Setup-<版本>.exe`，内置离线 AI 运行时、FFmpeg 与 yt-dlp，接收方无需安装任何依赖。

新版本安装包可以直接覆盖安装旧版本，音乐库与设置自动保留；发布流程见 [发布指南](./docs/release-guide.md)。

开发期间可运行：

```bash
npm run dev
```

然后在另一个终端运行 `npm start`。

## 项目结构

```text
src/
├─ main/           Electron 主进程、媒体服务与本地音频库
│  └─ adapters/    平台链接识别适配器
├─ renderer/       用户界面
└─ shared/         主进程与界面的共享类型
```

哔哩哔哩媒体解析当前通过 `youtube-dl-exec` 调用 yt-dlp。默认选择 `bestaudio/best` 并保留平台返回的 M4A、WebM/Opus 等原始格式，不再强制转码。平台页面或规则发生变化时，相关能力可能暂时失效。请勿使用本项目处理无权保存的内容。

## 已知边界

- 在线链接导入当前支持 B站 / 网易云 / Joox 公开内容；本地文件不受该限制。
- 在线歌词来自第三方公开接口（LRCLIB 为开放歌词库，其余为各平台公开端点），不保证持续可用，结果的准确性与授权状态以来源为准；网易云与 Joox 下载会自动附带歌词（LRC 优先），其余来源的在线歌词为纯文本，需要 AI 对齐或手动打点后才能同步显示。
- B站字幕歌词依赖视频本身携带 CC/AI 字幕，部分 AI 字幕需要登录后才会开放。
- `faster-whisper` 是普通语音识别模型，歌唱拖腔、多人合唱和方言仍可能需要人工复核。
- 精确裁切会输出 AAC 256kbps；快速裁切使用流复制，音质不变，但切点可能受关键帧影响。
