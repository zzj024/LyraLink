# LinkAudio 0.1.0 测试版

## 安装

双击 `LinkAudio-Setup-0.1.0.exe`，按照安装向导完成安装。

当前测试版没有购买 Windows 代码签名证书。如果 Windows SmartScreen 提示“Windows 已保护你的电脑”，请先确认文件来源和下方 SHA-256，然后点击“更多信息”→“仍要运行”。

## 文件校验

```text
SHA-256:
345FBBE3849E2B4A027BD8F02C3550B0A87F582A4FBE0FAB01B11138B41E2764
```

## 离线组件

安装包已经包含：

- FFmpeg
- 便携 Python
- faster-whisper
- Whisper small 模型
- yt-dlp

本地播放、裁切、整理和 AI 歌词匹配不需要另外安装 Python 或 FFmpeg。B站链接下载本身仍然需要网络。
