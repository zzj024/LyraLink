# LyraLink 初版完整测试流程手册

## 1. 测试目标

本手册用于检查 LyraLink 的主要功能是否能够完整跑通，包括：

- B站公开音频导入
- 本地音频导入
- 音频信息与封面编辑
- 播放控制
- 文件夹、喜欢和播放列表
- 音频裁切与拆分
- 手动歌词匹配
- AI 歌词匹配及后续修改
- LRC 导入与导出
- 音频导出
- 回收站
- 音乐库备份与恢复
- 离线运行和异常恢复

本轮测试重点是功能正确性，不评价整体视觉设计，也不评价 AI 匹配准确率。

---

## 2. 测试前准备

### 2.1 建议准备的文件

准备一个专门的测试目录，并放入以下内容：

1. 一首 2～5 分钟的 MP3 歌曲。
2. 一首带有歌名、歌手和内嵌封面的 MP3 或 M4A。
3. 一首 FLAC。
4. 一首文件名包含中文、空格和括号的歌曲。
5. 一段 10～30 分钟、包含多首歌曲的长音频。
6. 一张横向图片。
7. 一张正方形封面。
8. 一个带时间标签的 LRC 文件。
9. 一份无时间标签的纯文本歌词。
10. 同一个音频文件的副本，用于测试重复检测。

建议文件示例：

```text
测试素材/
├─ 普通歌曲.mp3
├─ 带标签歌曲.m4a
├─ 无损歌曲.flac
├─ 中文 文件名（测试）.mp3
├─ 多首歌曲合集.mp3
├─ 普通歌曲-副本.mp3
├─ 横向图片.jpg
├─ 方形封面.png
├─ 测试歌词.lrc
└─ 纯文本歌词.txt
```

### 2.2 B站测试链接

准备一个满足以下条件的链接：

- 内容公开可访问。
- 不需要登录。
- 不属于会员、付费、私密或地区限制内容。
- 测试人员有权保存和处理。

同时准备三种输入形式：

1. 完整视频网址。
2. B站短链接。
3. 包含链接的完整分享文案。

### 2.3 测试记录

每发现一个问题，记录：

- 测试编号
- 操作步骤
- 实际结果
- 预期结果
- 是否必现
- 截图或录屏
- 使用的音频文件
- 错误提示全文

严重程度建议：

| 等级 | 含义 |
|---|---|
| 阻塞 | 软件打不开、数据丢失、无法继续测试 |
| 严重 | 核心功能不可用、音频损坏、裁切结果错误 |
| 一般 | 某个操作失败，但存在替代方法 |
| 轻微 | 提示、文字、布局或操作体验问题 |

## 3. 启动前自动检查

必须在源码项目目录打开 PowerShell。当前项目目录是：

```text
C:\Users\Administrator\Desktop\项目\link-audio
```

请注意：

- `C:\Users\Administrator\Desktop\项目\link-audio` 是源码目录，包含 `package.json`，可以执行 npm 命令。
- `C:\Users\Administrator\AppData\Roaming\link-audio` 是应用运行数据目录，用于保存音乐库和设置，不能在这里执行 npm 命令。

可以先执行：

```powershell
cd "C:\Users\Administrator\Desktop\项目\link-audio"
```

确认当前目录正确：

```powershell
Get-Location
Test-Path .\package.json
```

第二条命令应当返回 `True`。然后再运行：

```powershell
npm install
npm run check
npm test
npm run build
npm start
```

预期结果：

- `npm run check` 无 TypeScript 错误。
- Node 测试全部通过。
- Python 测试全部通过。
- Electron 窗口正常出现。
- 启动后没有白屏。
- 控制台没有导致程序退出的错误。

如果只进行日常功能测试，可以直接运行：

```powershell
npm start
```

## 4. 首次启动测试

### TC-001 首次使用引导

步骤：

1. 使用一份全新的应用数据启动软件。
2. 观察软件首次打开的页面。
3. 阅读本地处理、隐私和合法使用说明。
4. 不勾选合法使用确认，直接尝试保存设置。
5. 再勾选合法使用确认。
6. 将回收站保留天数设置为 `30`。
7. 保存设置。
8. 关闭并重新打开软件。

预期结果：

- 第一次启动会引导用户进入设置。
- 可以看到本地处理和隐私说明。
- 设置可以正常保存。
- 重启后合法使用确认和回收站天数仍然存在。
- 重启后不再重复显示首次使用引导。

### TC-002 未确认授权时导入链接

步骤：

1. 取消合法使用确认并保存。
2. 回到导入页面。
3. 粘贴一个有效 B站链接。
4. 点击“导入音频”。

预期结果：

- 不会开始下载。
- 自动进入或提示前往设置。
- 明确提示需要先完成合法使用确认。

## 5. 本地音频导入

### TC-101 单个本地音频导入

步骤：

1. 点击“导入本地音频”。
2. 选择 `普通歌曲.mp3`。
3. 等待导入完成。
4. 进入“我的音频”。
5. 点击歌曲进入详情。
6. 播放歌曲。

预期结果：

- 导入成功。
- 歌曲出现在音乐库中。
- 默认名称来自音频标签或文件名。
- 可以正常播放。
- 时长显示正确，允许有约 1 秒显示误差。
- 原始测试文件没有被移动、重命名或删除。

### TC-102 读取内嵌信息

步骤：

1. 导入 `带标签歌曲.m4a`。
2. 检查名称、作者、时长和封面。

预期结果：

- 优先显示音频内部的歌名和歌手。
- 可以读取准确时长。
- 如果文件有内嵌封面，应显示封面。
- 如果某项信息不存在，应使用文件名或“未知作者”兜底。

### TC-103 多格式导入

步骤：

1. 分别导入 MP3、M4A、FLAC、WAV、Ogg、Opus 和 WebM。
2. 逐个播放。

预期结果：

- 支持列表中的格式可以正常选择和导入。
- Electron 支持解码的格式可以正常播放。
- 不支持播放的格式应给出明确错误，不应白屏或卡死。

### TC-104 批量导入

步骤：

1. 点击“导入本地音频”。
2. 一次选择 3～5 个不同音频。
3. 等待操作完成。

预期结果：

- 所有文件成功时，一次性加入音乐库。
- 歌曲数量正确。
- 每首歌曲的信息互不混淆。

### TC-105 重复文件检测

步骤：

1. 导入 `普通歌曲.mp3`。
2. 再次导入同一个文件。
3. 再导入内容完全相同但文件名不同的副本。
4. 一次同时选择原文件和副本。

预期结果：

- 不会重复加入同一音频。
- 即使文件名不同，只要内容完全相同也能识别。
- 提示音乐库中已经存在对应歌曲。
- 批量选择中出现重复时，不应留下半套导入结果。

### TC-106 特殊文件名

步骤：

1. 导入名称包含中文、空格、括号和较长名称的文件。
2. 播放、编辑、导出并删除该歌曲。

预期结果：

- 全流程正常。
- 文件名不会导致程序报错。
- 软件生成的文件名不包含 Windows 禁止字符。

## 6. B站链接导入

### TC-201 完整网址导入

步骤：

1. 确认合法使用设置已勾选。
2. 粘贴有效的 B站完整网址。
3. 点击“导入音频”。
4. 观察任务状态。
5. 导入完成后播放歌曲。

预期结果：

- 能识别链接。
- 显示读取、下载和保存状态。
- 导入歌名、作者、封面和时长。
- 保存的是可用音频。
- 音频能够正常播放。

### TC-202 分享文案和短链接

分别测试：

1. 粘贴完整分享文案。
2. 粘贴 B站短链接。

预期结果：

- 可以从分享文案中提取链接。
- 如果短链接能够正常解析，应完成导入。
- 网络失败时给出可理解的提示。

### TC-203 不支持的链接

分别输入：

- 普通网页链接。
- 其他视频平台链接。
- 没有网址的文字。
- 格式错误的网址。

预期结果：

- 不开始下载。
- 提示目前支持的链接类型。
- 软件不会卡死或白屏。

### TC-204 重复链接

步骤：

1. 成功导入一个 B站链接。
2. 再次导入相同链接。

预期结果：

- 阻止重复导入。
- 提示该音频已经存在。

### TC-205 下载中断

步骤：

1. 开始导入一个较长音频。
2. 下载过程中断开网络。
3. 等待错误提示。
4. 恢复网络。
5. 在任务记录中点击重试。

预期结果：

- 任务明确显示失败。
- 错误信息不会消失得过快。
- 不会在音乐库中留下无法播放的记录。
- 不会留下 `.part` 等未完成文件。
- 恢复网络后可以重试。

## 8. 歌曲信息与封面

### TC-401 编辑基本信息

步骤：

1. 打开歌曲详情。
2. 点击“编辑信息”。
3. 修改歌曲名称和作者。
4. 加入喜欢。
5. 选择一个或多个文件夹。
6. 保存。
7. 重启软件。

预期结果：

- 详情页、音乐库和播放器立即显示新信息。
- 喜欢状态和文件夹归属正确。
- 重启后修改仍然存在。

### TC-402 取消编辑

步骤：

1. 修改名称、作者和封面。
2. 不保存，直接点击取消。
3. 再次打开编辑界面。

预期结果：

- 未保存的修改不会写入音乐库。
- 原名称、作者和封面保持不变。

### TC-403 封面裁剪

步骤：

1. 选择一张横向图片。
2. 调整缩放。
3. 调整水平和垂直位置。
4. 保存。
5. 关闭并重新打开歌曲详情。
6. 重启软件后再次查看。

预期结果：

- 可以看到取景调整效果。
- 最终保存为正方形封面。
- 保存后的封面与选择的取景区域一致。
- 重启后封面仍然存在。
- 原图片文件不被修改。

### TC-404 导出带元数据的音频

步骤：

1. 修改歌曲名称、作者和封面。
2. 点击“导出音频”。
3. 将文件保存到测试目录。
4. 使用 Windows 文件属性、VLC 或其他播放器查看导出文件。

预期结果：

- 导出的文件可以播放。
- 标题和歌手是修改后的内容。
- MP3、M4A、MP4 或 FLAC 在支持的情况下包含封面。
- 导出操作不改变音乐库中的原音频。
- 导出失败时不留下损坏的目标文件。

## 9. 喜欢、文件夹与播放列表

### TC-501 喜欢

步骤：

1. 将歌曲加入喜欢。
2. 点击左侧“喜欢”。
3. 取消喜欢。

预期结果：

- 加入后出现在喜欢列表。
- 取消后立即从喜欢列表消失。
- 歌曲本身仍然存在于“我的音频”。

### TC-502 文件夹创建与维护

步骤：

1. 点击文件夹旁的加号。
2. 创建“通勤”文件夹。
3. 尝试再次创建同名文件夹。
4. 重命名为“路上听”。
5. 删除该文件夹。

预期结果：

- 加号正常打开输入窗口。
- 新建文件夹立即显示。
- 不允许完全同名的文件夹。
- 重命名后导航栏立即更新。
- 删除文件夹不会删除其中歌曲。

### TC-503 拖动歌曲进入文件夹

步骤：

1. 创建一个文件夹。
2. 从音乐库拖动歌曲到左侧文件夹名称。
3. 打开该文件夹。

预期结果：

- 拖动完成后歌曲出现在文件夹内。
- 歌曲仍保留在“我的音频”。
- 重复拖入不会产生重复歌曲。

### TC-504 播放列表

步骤：

1. 新建播放列表。
2. 拖入三首歌曲。
3. 打开播放列表。
4. 拖动歌曲改变顺序。
5. 播放第一首并等待结束。
6. 将其中一首从播放列表移除。
7. 删除整个播放列表。

预期结果：

- 播放列表创建成功。
- 同一首歌不会在列表中重复出现。
- 拖动后顺序立即变化并被保存。
- 播放下一首时遵循列表顺序。
- 从列表移除不会删除歌曲文件。
- 删除播放列表不会删除歌曲。

### TC-505 下一首播放

步骤：

1. 播放歌曲 A。
2. 在歌曲 C 上点击“下一首播放”加号。
3. 等待歌曲 A 结束，或点击下一首。

预期结果：

- 下一首优先播放歌曲 C。
- 临时队列消费后恢复原播放顺序。

## 11. 图形化裁切与拆分

### TC-701 打开裁切界面

步骤：

1. 打开一首有明确时长的歌曲。
2. 点击“裁切 / 拆分”。

预期结果：

- 显示完整音频长方形时间轴。
- 显示波形或明确的波形加载失败提示。
- 总时长正确。
- 原音频没有立即发生改变。

### TC-702 播放和切点

步骤：

1. 点击三角形播放按钮。
2. 再次点击暂停。
3. 按空格播放。
4. 再按空格暂停。
5. 将播放头移动到中间。
6. 按 Enter。

预期结果：

- 按钮和空格都可以控制播放、暂停。
- Enter 在播放头位置切开。
- 原长方形变成两个连续片段。
- 切点位置与播放头一致。

### TC-703 连续拆分

步骤：

1. 在多个位置依次切开。
2. 检查所有片段时间。

预期结果：

- 可以连续增加切点。
- 片段之间没有重叠。
- 片段顺序正确。
- 总时间范围仍然覆盖原音频。

### TC-704 删除片段

步骤：

1. 选中开头片段。
2. 点击删除。
3. 选中结尾片段并删除。
4. 播放预览。

预期结果：

- 被删除片段从保留方案中消失。
- 预览播放会跳过删除区域。
- 此时磁盘中的原音频仍然完整。

### TC-705 撤销与重做

步骤：

1. 新增切点。
2. 删除一个片段。
3. 连续点击撤销。
4. 再连续点击重做。

预期结果：

- 撤销顺序正确。
- 重做可以恢复撤销的操作。
- 不会产生重叠或负数时长片段。

### TC-706 精确调整与缩放

步骤：

1. 使用 `-0.5s`、`-0.1s`、`+0.1s`、`+0.5s`。
2. 直接输入播放头时间。
3. 调整时间轴缩放。

预期结果：

- 播放头按指定数值移动。
- 不会移动到 0 秒之前或音频结束之后。
- 缩放后仍可正确选择和拆分片段。

### TC-707 取消未保存方案

步骤：

1. 做多个切点并删除片段。
2. 点击取消。
3. 在确认窗口选择“不放弃”。
4. 再次取消并确认放弃。

预期结果：

- 有修改时会询问是否放弃。
- 选择不放弃后留在编辑界面。
- 确认放弃后关闭界面。
- 音乐库和原音频没有变化。

### TC-708 编辑每段信息

步骤：

发布初版前至少完整执行一次：

1. 首次启动并完成设置。
