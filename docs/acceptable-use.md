# 合法使用政策

LinkAudio 是本地媒体处理工具，仅用于处理以下内容：

- 用户本人创作并拥有相应权利的内容；
- 已取得权利人明确授权的内容；
- 处于公有领域或采用允许相应使用方式之许可的内容；
- 平台明确允许用户保存、导出或离线处理的内容。

禁止使用本项目：

- 绕过登录、付费、会员、私密、地区限制、DRM 或其他访问控制；
- 未经授权下载、传播、出售或公开表演受版权保护的内容；
- 批量搬运或重新发布其他创作者的作品；
- 获取非公开数据、共享账号凭证或规避平台安全措施；
- 从事违反所在地法律或相应平台协议的活动。

项目维护者不提供公共解析服务，不托管媒体内容，也不会要求用户提交账号、密码或浏览器 Cookie。平台规则和法律可能发生变化，用户有责任在使用前确认自己拥有必要权利。
